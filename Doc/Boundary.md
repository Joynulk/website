# Boundary (সীমা ও মনে রাখার বিষয়)

লেখা: 2026-10-29, হালনাগাদ: 2026-10-29

এই ফাইলে থাকে যে সীমাগুলো এখন মেনে চলা হচ্ছে, কিন্তু নিরাপদ launch-এর আগে বা নির্দিষ্ট কাজের আগে ঠিক করতে হবে। প্রতিটির "কখন ঠিক করতে হবে" আলাদা লেখা আছে।

## 1. Supabase-এর নিজস্ব ইমেইল সীমিত
| বিষয় | বিবরণ |
|---|---|
| সমস্যা | সাইন আপ ও পাসওয়ার্ড রিসেটের ইমেইল এখন Supabase-এর বিল্ট-ইন ইমেইল দিয়ে যায়। এতে ঘণ্টায় অল্প কয়েকটা মেইল পাঠানো যায়। সীমার সঠিক সংখ্যা আমি যাচাই করি নি, Supabase dashboard-এ আপনার প্ল্যানে দেখুন। |
| ফল | বেশি পরিমাণে রিসেট ইমেইল টেস্ট করলে ইমেইল আটকে যাবে। Launch-এর পর অনেক ক্রেতা একসাথে সাইন আপ করলে সবাই ইমেইল পাবে না। |
| কখন ঠিক করতে হবে | **Launch-এর আগে**, ইমেইল যাচাই চালু করার সাথে। |
| কী করতে হবে | নিজস্ব SMTP সেবা ঠিক করা (যেমন Resend, Brevo, বা আপনার domain-এর ইমেইল) ও Supabase -> Authentication-এ SMTP সেটিংে বসানো। তারপর "Confirm email" চালু করা। সেরা হয় নিজের domain থাকলে (SPF/DKIM সেটআপ)। |
| নিজের করণীয় | SMTP সেবা বাছাই ও মাসিক খরচ দেখার সিদ্ধান্ত আপনার |
| কী দিয়ে পরীক্ষা | [9.auth.md](9.auth.md)-এর A1, A8 |
| স্থিতি | না করা |

## 2. Token ব্রাউজারে থাকে (আর পণ্যের নাম escape করার কাজ হয়েছে)
| বিষয় | বিবরণ |
|---|---|
| সমস্যা | লগইনের token (`mela_session`) ব্রাউজারের localStorage-এ থাকে। একই সাইটে কোনো স্ক্রিপ্ট চললে (XSS) সেটা এই token পড়তে পারে। Admin-এর token চুরি হলে পুরো দোকান হাতছাড়া হবে। |
| যা করা হয়েছে (ধাপ D) | পণ্যের নাম, বিবরণ, emoji, ক্যাটাগরির নাম, সার্চ শব্দ ও কার্টের তথ্য সব জায়গায় `esc()` দিয়ে দেখানো হয়। রঙের মান `#rrggbb` না হলে বাতিল। পরীক্ষা (X10, [10.admin.md](10.admin.md)) বাকি। |
| যা এখনো বাকি (সীমা) | (1) Token localStorage-এ থাকা। (2) সাইটে সীমিত script-এর অনুমতি (CSP) নেই, hosting header দিতে দেয় কি না ভাবা বাকি। |
| কখন ঠিক করতে হবে | Launch-এর আগে। আর ক্রেতার ও admin-এর অ্যাকাউন্টে শক্ত পাসওয়ার্ড ও অচেনা লিংকে সাবধানতা এখনই মানা ভালো। |
| নিজের করণীয় | admin অ্যাকাউন্টে অন্য পাসওয়ার্ড ব্যবহার করা |
| স্থিতি | আংশিক: escape কোডে আছে (পরীক্ষা বাকি), বাকি দুটি সীমা আছে |
