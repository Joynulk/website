# Boundary (সীমা ও মনে রাখার বিষয়)

লেখা: 2026-10-29

এই ফাইলে থাকে যে সীমাগুলো এখন মেনে চলা হচ্ছে, কিন্তু নিরাপদ launch-এর আগে বা নির্দিষ্ট কাজের আগে ঠিক করতে হবে। প্রতিটির "কখন ঠিক করতে হবে" আলাদা লেখা আছে।

## 1. Supabase-এর নিজস্ব ইমেইল সীমিত
| বিষয় | বিবরণ |
|---|---|
| সমস্যা | সাইন আপ ও পাসওয়ার্ড রিসেটের ইমেইল এখন Supabase-এর বিল্ট-ইন ইমেইল দিয়ে যায়। এতে ঘণ্টায় অল্প কয়েকটা মেইল পাঠানো যায়। সীমার সঠিক সংখ্যা আমি যাচাই করি নি, Supabase dashboard-এ আপনার প্ল্যানে দেখুন। |
| ফল | বেশি পরিমাণে রিসেট ইমেইল টেস্ট করলে ইমেইল আটকে যাবে। Launch-এর পর অনেক ক্রেতা একসাথে সাইন আপ করলে সবাই ইমেইল পাবে না। |
| কখন ঠিক করতে হবে | **Launch-এর আগে**, ইমেইল যাচাই চালু করার সাথে। |
| কী করতে হবে | নিজস্ব SMTP সেবা ঠিক করা (যেমন Resend, Brevo, বা আপনার domain-এর ইমেইল) ও Supabase -> Authentication-এ SMTP সেটিংে বসানো। তারপর "Confirm email" চালু করা। সেরা হয় নিজের domain থাকলে (SPF/DKIM সেটআপ)। |
| নিজের করণীয় | SMTP সেবা বাছাই ও মাসিক খরচ দেখার সিদ্ধান্ত আপনার |
| কী দিয়ে পরীক্ষা | [9.auth.md](9.auth.md)-এর A1, A8 |
| স্থিতি | না করা |

## 2. Token ব্রাউজারে এবং পণ্যের নাম escape করা হয় না
| বিষয় | বিবরণ |
|---|---|
| সমস্যা | লগইনের token (`mela_session`) ব্রাউজারের localStorage-এ থাকে। একই সাইটে কোনো স্ক্রিপ্ট চললে (XSS) সেটা এই token পড়তে পারে। আবার পণ্যের নাম ও বিবরণ সাইটে `innerHTML` দিয়ে বসানো হয়, escape ছাড়া। অর্থাৎ যে পণ্য যোগ করবে সে নামের ভেতর স্ক্রিপ্ট লুকিয়ে দিলে সব ক্রেতার ব্রাউজারে সেটা চলবে। |
| এখন কেন তুলনামূলক কম ঝুঁকি | পণ্য শুধু admin (আপনি) Supabase dashboard থেকে যোগ করতে পারেন। ক্রেতার লেখা নাম/ঠিকানা দেখানোর সময় `esc()` ব্যবহার হয়। |
| কখন ঠিক করতে হবে | **Admin panel বানানোর আগে**। Admin panel-এ পণ্য ও অর্ডার দেখানো হবে, তখন admin-এর token চুরি হলে পুরো দোকান হাতছাড়া হবে। তাই অন্যত তার আগে শেষ করতে হবে। |
| কী করতে হবে | (1) সব জায়গায় ক্রেতার লেখা ও পণ্যের নাম/বিবরণ `esc()` বা `textContent` দিয়ে দেখানো। (2) সাইটে সীমিত script-এর অনুমতি (CSP) ভাবা, hosting যদি header দিতে দেয়। (3) পরে দরকার হলে token কোন ডিভাইসে সব অ্যাকাউন্টে সংরক্ষিত তা সীমিত করা। |
| কী দিয়ে পরীক্ষা | সর্বনিম্ন: Supabase-এ একটা টেস্ট পণ্যের নাম `<b>টেস্ট</b>` রাখলে সাইটে সেটা মোটা অক্ষরে না দেখিয়ে হুবহু লেখাসহ দেখাতে হবে। |
| স্থিতি | না করা |
