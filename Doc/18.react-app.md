# 18. React অ্যাপ (Vite) — পরীক্ষামূলক সংস্করণ

শেষ হালনাগাদ: 2026-11-06

**অবস্থা:** প্রথম ধাপের কোড লেখা হয়েছে। **কোথাও চালিয়ে বা বিল্ড করে দেখা হয়নি।** পুরোনো স্ট্যাটিক সাইট যেমন আছে তেমনই চলছে।

## কী বানানো হয়েছে
সবকিছু `react-app/` ফোল্ডারে। React 18 + Vite + react-router (HashRouter, তাই `#/shop`-এর মতো ঠিকানা)।

| ফাইল | কাজ |
|---|---|
| `src/lib.js` | Supabase-এর সঙ্গে কথা (পণ্য, অর্ডার, বাবহারকারী লগইন, ট্র্যাক), ফরম্যাটিং |
| `src/store.js` | একটি ছোট অ্যাপ-স্টেট: কার্ট, প্রিয় তালিকা, লগইন, পণ্যের তালিকা, থিম, টোস্ট |
| `src/Layout.jsx` | হেডার, স্লাইড মেনু, ফুটার, WhatsApp/কার্ট বোতাম, পণ্যের কার্ড |
| `src/pages.jsx` | হোম, দোকান, পণ্য, কার্ট ও অর্ডার, ট্র্যাক, প্রিয় তালিকা, সহায়তার পেজ |
| `src/account.jsx` | লগইন, সাইন আপ, পাসওয়ার্ড ভুলে গেছেন, অ্যাকাউন্ট |
| `src/styles.css` | পুরোনো সাইটের হালকা নীল ডিজাইন (হুবহু একই রঙ ও ক্লাস) |
| `.github/workflows/pages.yml` | push করলে নিজে বিল্ড করে সাইটে তুলে দেয় |

## পুরোনো সাইটের সঙ্গে মিল
- একই database, একই ব্রাউজার স্টোরেজের চাবি (`mela_cart`, `mela_wish`, `mela_session`…)। তাই এক সাইটের কার্ট, প্রিয় তালিকা ও লগইন অন্য সাইটেও দেখা যাবে।
- Admin পেজ আগের মতো `admin.html` (এখনো React-এ আনা হয়নি)। পাসওয়ার্ড রিসেটের নতুন পাসওয়ার্ড দেওয়ার পেজও পুরোনো `reset-password.html`।

## প্রথমবার চালু করার ধাপ (আপনার করণীয়)
1. GitHub repo → **Settings → Pages → Build and deployment → Source = “GitHub Actions”**।
2. repo → **Actions** ট্যাবে “Deploy site” ওয়ার্কফ্লোতে **Run workflow** চাপুন (বা যে কোনো push-এর পর নিজে চলবে)।
3. সবুজ টিক আসলে খুলুন: `https://joynulk.github.io/website/app/`।
4. লাল ✕ আসলে ওই run-এর log সামনে দিয়ে বা স্ক্রিনশট দিন; আমি ঠিক করে দেব।

সাবধানতা: ধাপ ১ করার পর ধাপ ২-এর আগে পুরোনো সাইট বন্ধ হয় না (workflow সেটাও তুলে দেয়, শুধু `/app/` যোগ করে)। তবে ধাপ ১-এর আগে Pages-এর Source বদলালে বিল্ড সফল না হওয়া পর্যন্ত সাইট দেখা যাবে না। তাই ধাপ ১ ও ২ পরপর করুন।

## কাজ বাকি (পরের ধাপ)
- Admin পেজ React-এ আনা
- পাসওয়ার্ড রিসেট পেজ React-এ আনা
- পণ্যের আলাদা শেয়ার প্রিভিউ — React SPA-তেও সম্ভব নয় (চ্যাট অ্যাপ স্ক্রিপ্ট চালায় না); সেজন্য Next.js বা সার্ভার লাগবে
- পরীক্ষা: সব পেজ ফোনে (হোম, দোকানের ফিল্টার, পণ্য, কার্ট ও অর্ডার, ট্র্যাক, লগইন, অ্যাকাউন্ট, স্লাইড মেনু, থিম)
- `/app/` ঠিক হলে পুরোনো সাইট বদলে দেওয়া (তখন `noindex` সরিয়ে `index.html` পরিবর্তন)

## জানা সীমা
- নতুন সাইটে `noindex` আছে, যাতে Google-এ দুইটি কপি না দেখায়।
- পণ্যের তালিকা প্রথমবার সাইটে গিয়ে লোড হয় (পরে ব্রাউজারে ক্যাশ থাকে); ইন্টারনেট না থাকলে প্রথমবার ফাঁকা দেখাবে।
- অ্যাপ কোড আমি কোথাও চালিয়ে দেখিনি (এখানে বিল্ড টুল অ্যাক্সেস নেই), তাই প্রথম বিল্ডে ভুল থাকতে পারে।
