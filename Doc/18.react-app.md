# 18. React অ্যাপ (Vite) — পরীক্ষামূলক সংস্করণ

শেষ হালনাগাদ: 2026-11-06

**অবস্থা:** প্রথম ধাপের কোড লেখা হয়েছে। **কোথাও চালিয়ে বা বিল্ড করে দেখা হয়নি।** পুরোনো স্ট্যাটিক সাইট যেমন আছে তেমনই চলছে।

## Branch ব্যবস্থা
- **`main`**: স্ট্যাটিক সাইট (লাইভ)।
- **`react-app`**: React-এর সব কাজ এখানে। এখন থেকে React-এর কোনো পরিবর্তন `main`-এ যাবে না। (আগের বারে `main`-এও `react-app/` ফোল্ডারে একদফা কোড গিয়েছিল, সেটা পুরোনো কপি, বিল্ডে ব্যবহার হয় না।)
- Workflow `main` থেকে স্ট্যাটিক পেজ আর `react-app` branch থেকে React নিয়ে একসাথে বিল্ড করে প্রকাশ করে। `react-app`-এ নতুন কাজ push হলে Actions ট্যাবে “Deploy site” **আবার চালান** (নিজে চলবে না)।
- ফলাফল তৃতীয় কোনো জায়গায় নয়: সাইটে `/app/` পথে।

## কী বানানো হয়েছে
সবকিছু `react-app/` ফোল্ডারে। React 18 + Vite + react-router (HashRouter, তাই `#/shop`-এর মতো ঠিকানা)।

| ফাইল | কাজ |
|---|---|
| `src/lib.js` | Supabase-এর সঙ্গে কথা (পণ্য, অর্ডার, ব্যবহারকারী লগইন, ট্র্যাক), ফরম্যাটিং |
| `src/store.js` | একটি ছোট অ্যাপ-স্টেট: কার্ট, প্রিয় তালিকা, লগইন, পণ্যের তালিকা, থিম, টোস্ট |
| `src/Layout.jsx` | হেডার, স্লাইড মেনু, ফুটার, WhatsApp/কার্ট বোতাম, পণ্যের কার্ড |
| `src/pages.jsx` | হোম, দোকান, পণ্য, কার্ট ও অর্ডার, ট্র্যাক, প্রিয় তালিকা, সহায়তার পেজ |
| `src/account.jsx` | লগইন, সাইন আপ, পাসওয়ার্ড ভুলে গেছেন, অ্যাকাউন্ট |
| `src/styles.css` | পুরোনো সাইটের হালকা নীল ডিজাইন (হুবহু একই রঙ ও ক্লাস) |
| `pages.yml.txt` | workflow (হাতে `.github/workflows/pages.yml` নামে বসাতে হবে, নিচে দেখুন) |

## পুরোনো সাইটের সঙ্গে মিল
- একই database, একই ব্রাউজার স্টোরেজের চাবি (`mela_cart`, `mela_wish`, `mela_session`…)। তাই এক সাইটের কার্ট, প্রিয় তালিকা ও লগইন অন্য সাইটেও দেখা যাবে।
- Admin পেজ আগের মতো `admin.html` (এখনো React-এ আনা হয়নি)। নতুন পাসওয়ার্ড দেওয়ার পেজও পুরোনো `reset-password.html`।

## প্রথমবার চালু করার ধাপ (আপনার করণীয়, এই ক্রমে)
1. অ্যাপ বিল্ডের workflow বসান: GitHub-এ `main` branch নির্বাচন করে **Add file → Create new file**, নাম `.github/workflows/pages.yml`, `react-app` branchের `react-app/pages.yml.txt` ফাইলের মাথার মন্তব্য বাদ দিয়ে পুরো বাকিটা পেস্ট করুন, Commit। (GitHub আমার টুলকে এই ফোল্ডারে ফাইল বানাতে দেয় না।)
2. **Settings → Pages → Build and deployment → Source = “GitHub Actions”**।
3. **Actions** ট্যাবে “Deploy site” → **Run workflow** (branch: main)।
4. সবুজ টিক আসলে `https://joynulk.github.io/website/app/` খুলুন।
5. লাল ✕ আসলে ওই run-এর log সামনে দিয়ে বা স্ক্রিনশট দিন; আমি `react-app` branch-এ ঠিক করে দেব, আপনি আবার চালাবেন।

সাবধানতা: ধাপ ২ করার পর ধাপ ৩ সফল না হওয়া পর্যন্ত Pages-এর সাইট নামতে পারে। তাই ধাপ ১–৩ দ্রুত পরপর করুন। বিল্ড ব্যর্থ হলে আগের deploy-ই থাকে।

## কাজ বাকি (`react-app` branch-এ করা হবে)
- Admin পেজ React-এ আনা
- পাসওয়ার্ড রিসেটের নতুন পাসওয়ার্ড পেজ React-এ আনা
- পরীক্ষা: সব পেজ ফোনে (হোম, দোকানের ফিল্টার, পণ্য, কার্ট ও অর্ডার, ট্র্যাক, লগইন, অ্যাকাউন্ট, স্লাইড মেনু, থিম)
- `/app/` ঠিক হলে পুরোনো সাইট বদলে দেওয়া (তখন `noindex` সরিয়ে `main`-এ মার্জ)

## জানা সীমা ও সম্ভাব্য ছোট খুঁট
- নতুন সাইটে `noindex` আছে, যাতে Google-এ দুইটি কপি না দেখায়।
- পণ্যের আলাদা শেয়ার প্রিভিউ সম্ভব নয় (SPA, চ্যাট অ্যাপ স্ক্রিপ্ট চালায় না)। দরকার হলে নাকি Next.js।
- পণ্যের তালিকা প্রথমবার সাইটে গিয়ে লোড হয় (পরে ক্যাশ থাকে)।
- লগইনের পর স্লাইড মেনু খোলা থাকলে টোস্ট দেখালে ফোকাস বন্ধ বোতামে ফিরে যেতে পারে (ছোট খুঁট, পরে ঠিক করা যাবে)।
- কার্ট পেজে দাম/স্টক প্রথমে ব্রাউজারের ক্যাশ অনুযায়ী মিলানো হয়; নতুন ক্যাটালগ আসার পর আবার মিলায় না। অর্ডারের সময় সার্ভার সবসময় দাম/স্টক নিজে যাচাই করে, তাই ভুল অর্ডার হবে না।
- অ্যাপ কোড আমি কোথাও চালিয়ে দেখিনি (এখানে বিল্ড টুল অ্যাক্সেস নেই), তাই প্রথম বিল্ডে ভুল থাকতে পারে।
