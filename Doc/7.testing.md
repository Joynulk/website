## ক. Database পরীক্ষা (Supabase SQL Editor)
আসল ডেটা নষ্ট না করতে এই block-এ শেষে ইচ্ছা করে error তোলা হয়, ফলে সব লেখা ফিরে যায় (rollback)। Error বার্তায় ফল দেখা যায়। (অর্ডার নম্বরের sequence এক ধাপ এগিয়ে যায়, এটা স্বাভাবিক।)
```sql
do $$ declare r json; begin
  r := place_order('টেস্ট ক্রেতা','01712345678','ঢাকা, টেস্ট ঠিকানা',
        '[{"id":1,"qty":1,"gift":true},{"id":14,"qty":2}]'::jsonb);
  raise exception 'TEST_RESULT %', r;
end $$;
```
| # | পরীক্ষা | প্রত্যাশিত | ফল |
|---|---|---|---|
| D1 | উপরের block | মোট 5040 (4800+60 + 90x2 = 5040, ডেলিভারি ফ্রি) | |
| D2 | ফোন `0123` দিয়ে | `invalid details` | |
| D3 | `qty` 0 বা 21 | `bad quantity` | |
| D4 | খালি `[]` | `empty cart` | |
| D5 | না থাকা পণ্য `id: 9999` | `product not found` | |
| D6 | সাবটোটাল 2000-এর নিচে (যেমন id 14 একটা) | ডেলিভারি 60, মোট 150 | |
| D7 | `active=false` করা পণ্য | `product not found` | |

## ঘ. UI ও accessibility
- 360px চওড়া ফোনে সব পেজ কাটা বা সরে না গিয়ে দেখা যায়।
- কিবোর্ড দিয়ে (Tab) সব বাটন ও লিংকে যাওয়া যায়, focus চিহ্ন দেখা যায়।
- Dark mode-এ লেখা পড়া যায়।
- ছোট ছবি-ছাড়া বাটনে (♡, +, −, ✕) স্ক্রিন-রিডারের নাম আছে।
