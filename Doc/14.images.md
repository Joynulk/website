# 14. পণ্যের ছবি (Cloudinary)

শেষ হালনাগাদ: 2026-11-03

**অবস্থা:** কোড, database, Edge Function ও `CLOUDINARY_URL` secret সব সেট আছে। মালিক ফোনে admin থেকে ছবি তুলেছেন ও দোকান পেজে (কাতান শাড়ি) ছবি দেখা গেছে। পরীক্ষার বাকি অংশ নিচের তালিকায়।

## নকাশা
1. admin পণ্য ফর্মে ছবি বাছেন।
2. ব্রাউজার ছবিটি নিজে ছোট করে (সর্বোচ্চ ১২০০px, JPEG)।
3. ব্রাউজার Edge Function `cloudinary-sign`-কে ডাকে (লগইন token সহ)। ফাংশন database-এ `is_admin()` দিয়ে পরীক্ষা করে দেখে মালিক admin কি না। হলে সাইন করা আপলোডের টিকিট দেয় (প্রায় এক ঘন্টার মধ্যে বাতিল হয়ে যাবে, Cloudinary-র নিয়ম)।
4. ব্রাউজার সরাসরি Cloudinary-তে ছবি তোলে (`mela/products` ফোল্ডারে, শুধু jpg/png/webp)।
5. পণ্যের `image_url`-এ ফেরত আসা ঠিকানা সংরক্ষিত হয়। ক্রেতারা ছবি দেখেন Cloudinary থেকে, `f_auto,q_auto,c_fill,ar_1:1,w_…` দিয়ে বাগ করা সাইজে।

## Secret সাবধানতা
- `CLOUDINARY_URL`-এ API secret আছে। এটা repo, ব্রাউজারের কোড বা চ্যাটে **কখনো দেবেন না**। শুধু Supabase → Edge Functions → Secrets-এ।
- ভুলে কোথাও প্রকাশ পেলে Cloudinary dashboard থেকে API key বদলে নিন আর secret আবার বসান।
- `image_url` কলামে database নিজে শুধু `https://res.cloudinary.com/…/image/upload/…` ঠিকানা নেয়, অন্য কিছু নয়।

## সেটআপ (করা হয়েছে)
1. Cloudinary dashboard → API Keys থেকে `CLOUDINARY_URL` কপি (`cloudinary://…@আপনার-cloud-name`)।
2. Supabase → Edge Functions → Secrets → নাম `CLOUDINARY_URL`।
3. admin → পণ্য → সম্পাদনা → ছবি বাছুন → সংরক্ষণ।

## নিরাপত্তা ও সীমা
- আপলোড শুধু admin পারে। ক্রেতারা পারে না।
- কার্ট ও অর্ডারে এখনো শুধু emoji দেখায় (ছবি কার্টে নেই)। দোকান, হোম, প্রিয় তালিকা, পণ্য পেজ ও admin-এ ছবি আছে।
- ক্যাটাগরিতে ছবি নেই (শুধু emoji ও রঙ)।
- পুরোনো ছবি বদলালে আগেরটা Cloudinary-তে থেকে যায় (মুছা হয় না)। দরকার হলে Cloudinary dashboard থেকে মুছুন।
- সাইন করার Edge Function-এ সীমা (রেট লিমিট) নেই। শুধু admin পারে, তাই ইস্যু নেই।

| I2 | secret বসিয়ে ছবি বাছুন | প্রিভিউ আসে, “ছবি যোগ হয়েছে” | পাস (2026-11-03, মালিকের ফোনে আপলোড সফল) |
| I3 | সংরক্ষণ করে দোকান পেজ রিফ্রেশ | কার্ডে emoji-র বদলে ছবি | পাস (শলপ পেজে কাতান শাড়ির ছবি দেখা গেছে, বাকি তিনটিতে তখনো emoji) |
| I4 | ফোনের ক্যামেরার বড় ছবি (৪–৫ MB) দিন | ছোট হয়ে তোলা হয় | বাকি |

| I6 | ক্রেতা হিসেবে লগইন করে আপলোড হয় না (মালিক নিজে অ্যাডমিন ছাড়া অ্যাকাউন্টে চেষ্টা করলে জানা যাবে) | “আপলোডের অনুমতি পাওয়া যায়নি” | বাকি |

## পরের সম্ভাব্য কাজ
কার্ট ও অর্ডারে ছবি, ক্যাটাগরির ছবি, একাধিক ছবির গ্যালারি। মালিক এখনো সিদ্ধান্ত দেননি।
